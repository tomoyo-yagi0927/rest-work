「架空のコワーキングスペースのWebサイト制作」ポートフォリオ
サイト名：「Rest-Work」（レストワーク）
制作：八木 友代
https://yagimaru.net/portfolio/rest-work/

01｜制作概要
架空のコワーキングスペースを題材に制作。ネーミング「Rest-Work」（レストワーク）とし、施設紹介・料金・利用ガイド・アクセス・お
問い合わせなどを備えた複数ページのWebサイトを制作。

02｜企画・情報設計
「どんな施設か」「いくらで使えるか」「どう利用するか」を利用者が迷わず把握できることを重視。トップページから各情報へ自然につな
がるサイト構成と導線を設計。

03｜レイアウト・ビジュアルデザイン・UI
メインカラーはグリーン（#018B6C）、アクセントはイエロー（#E6BB36）。写真・余白・文字の階層を調整。ボタンはシンプルで視認性
の高いものに統一。レスポンシブ設計。PC・タブレット・スマートフォンに対応し、小画面ではハンバーガーメニューを採用。

04｜ロゴ制作：ChatGPT × Illustrator
ロゴはChatGPTにデザイン仕様を具体的に指定して画像を生成。その後、Adobe
Illustratorでベクターデータを作成した。AIによるアイデアの可視化から、制作ツールで扱えるロゴデータへの展開まで実施。

05｜ChatGPTの活用：企画・設計・制作判断
ChatGPTを企画・制作の壁打ちとして活用。サイトのコンセプトや名称、掲載情報、ページ構成、画面の見せ方、演出案を対話しながら整理
した。実装時には要件や修正内容を具体的な指示文にまとめ、制作の方向性を明確化。提案の採否や最終的なデザイン判断は自ら行った。

06｜Codexの活用：AIコーディング
自分で定めた構成・レイアウト・配色・動作要件をもとに、CodexへHTML／CSS／JavaScriptの実装や修正を指示。生成結果をブラウザで確
認し、意図との差分を追加指示で調整した。ChatGPTによる要件整理とCodexによる実装を使い分け、設計・検証・品質判断は自分で担う制
作手法を採用。

07｜実装上のポイント
HTML／CSS／JavaScriptによる静的サイト。初回訪問時のみ表示する波紋（Ripple）型ローディングアニメーションを実装。見る人に印象を
与える。セッション内での再表示抑制や動きの軽減設定にも配慮。公開用ビルドでCSS／JavaScript等のキャッシュ更新に対応。

08｜開発環境・検証
Windows 11／Visual Studio Code／Git・GitHub／ChatGPT／Codex／Adobe
Illustratorを使用。GitHubで変更履歴を管理。ローカル表示、画面幅別のレイアウト、リンク・画像参照、JavaScriptの動作を確認。

09｜この作品のアピールポイント
Web制作の実務経験を基盤に、AIを企画支援と実装支援に適切に組み込み、構想から情報設計・デザイン・実装・検証まで主体的に進めるこ
とができた。AIの出力をそのまま採用せず、目的に照らして評価・改善できること。
